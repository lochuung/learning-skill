## 👤 Learner Profile & Personalization
- **Background & Analogies:** Backend Software Engineer (4 yrs) — uses systems/metrics analogies (e.g., Balance Sheet = snapshot of system state; Cash Flow = real-time I/O throughput).
- **Goal (Definition of Done):** Independently read a public company's 10-K/annual report and write a 1-page investment memo with clear bull/bear risks in **6 weeks** (4 hrs/week).
- **Domain Archetype:** Business / Knowledge
- **Verified Level:** Beginner *(Diagnostic probes: 1/3 — knew revenue vs profit, missed accrual vs cash flow and EV/EBITDA).*
- **Personalization Decisions:**
  - **Extended:** Cash Flow Statement & working capital (highest-signal gap from probes).
  - **Constraints Respected:** Zero budget (uses free SEC EDGAR filings + Yahoo Finance), 30-min weekday evenings + 1.5h Saturday block.
