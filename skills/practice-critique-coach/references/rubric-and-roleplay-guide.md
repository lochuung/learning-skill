# Rubric & Roleplay Reference Guide

## 1. Observable Rubric Templates by Domain Archetype

Score every criterion on a 1–3 scale (`1 = Missing/Weak`, `2 = Functional`, `3 = Strong/Proficient`). Customize criteria to the user's specific task.

| Archetype | Default Observable Criteria (pick 3–5) |
| :--- | :--- |
| **Technical / Tooling** | Correctness & edge-case handling · Readability/structure · Performance/security/cost hygiene · Idiomatic tool usage · Verifiability (tests/checks) |
| **Exam / Academic** | Accuracy of core claim · Step-by-step reasoning clarity · Elimination of distractors/traps · Precision of terminology · Time efficiency |
| **Foreign Language** | Task completion & coherence · Grammatical accuracy · Lexical range & natural collocations · Register/tone fit · Fluency/conciseness |
| **Creative / Craft** | Alignment with brief & audience · Visual/structural hierarchy · Originality/voice · Craft execution/polish · Economy (no fluff) |
| **Business / Knowledge** | Clear recommendation upfront (BLUF) · Evidence/data rigor · Trade-offs & counterarguments addressed · Actionability · Audience clarity |
| **Physical / Soft Skills** | Clear objective/framing · Active listening / responsiveness · Composure & pacing · Handling pushback/objections · Concrete next step/close |

## 2. Roleplay Protocol

Before Turn 1, state briefly:
- **My role:** `<persona, attitude, hidden constraint>`
- **Your role & goal:** `<what success looks like>`
- **Rubric:** `<3 criteria I will grade you on at the end>`
- **Control words:** Say `"pause"` for a mid-scene hint, or `"debrief"` to end early and get scored.

During the roleplay:
- Escalate realism gradually (start neutral → introduce 1 realistic objection or curveball mid-way).
- Never break character to lecture mid-scene unless the user asks for `"pause"`.

## 3. Error Log Entry Format (for Roadmap Repos)

When logging a mistake into `Week-NN-Practice.md` or an error log:

```markdown
- **[Date] Sub-skill:** <name>
  - **Mistake:** <what happened>
  - **Root cause:** <concept gap / rushed / trap>
  - **Fix / Rule:** <concrete rule to apply next time>
```
