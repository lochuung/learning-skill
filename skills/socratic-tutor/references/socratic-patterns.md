# Socratic Tutoring Patterns

## 1. The Scaffolding Ladder

Move up only when the learner clears the current rung:

| Rung | Goal | Tutor Move | Example Prompt |
| :--- | :--- | :--- | :--- |
| **1. Intuition** | Understand *why* the concept exists | Analogy + plain-language purpose | *"Before the formula, why do you think analysts don't just look at revenue?"* |
| **2. Mechanics** | Trace how it works step-by-step | Diagram / worked example | *"Walk me through what happens at step 2 if input doubles."* |
| **3. Discrimination** | Separate from look-alike concepts | Side-by-side comparison table | *"How is X different from Y in this specific case?"* |
| **4. Edge Cases** | Spot where the mental model breaks | Counter-example / stress test | *"When would this rule give the wrong answer?"* |
| **5. Transfer** | Apply to learner's real context | Real-world mini-scenario | *"How would you apply this to your own project / job / goal?"* |

## 2. Domain-Adaptive Explanations

- **Technical / Tooling**: Mental model → data/control flow Mermaid diagram → minimal runnable example → "what breaks if we remove line X?"
- **Exam / Academic**: Core principle → common exam trap comparison table → 1 worked scenario showing why distractors are wrong.
- **Foreign Language**: Meaning + register/nuance → 2 natural contrasts (natural vs awkward) → learner produces 1 original sentence.
- **Creative / Craft**: Principle → "weak vs strong" teardown of a real example → learner spots *why* one works better.
- **Business / Knowledge**: Framework → 1 real-world case application → trade-off question ("what risk does this create?").
- **Physical / Soft Skills**: Core cue/mechanic → "before vs after" script or movement contrast → learner adapts 1 line to their own situation.

## 3. Anti-Patterns to Avoid

- **Endless interrogation**: Never ask >2 consecutive questions when the learner says "I don't know." Explain clearly, then re-engage.
- **Jargon before intuition**: Always introduce the *idea* before naming the *term*.
- **Over-praising vague answers**: If the learner says *"it makes things faster"*, gently probe: *"Faster in what exact way — less work done, or doing work in parallel?"*
- **Monologuing**: Keep each tutoring turn under ~200–250 words unless the learner explicitly asks for a deep reference explanation.
