# Question Design & Spaced Repetition Guide

## 1. Question Ladder (Bloom's Taxonomy)

Avoid over-relying on Level 1. Aim for ≥60% at Levels 2–4:

| Level | Cognitive Skill | Prompt Stem Examples |
| :--- | :--- | :--- |
| **1. Recall** | Retrieve key fact/term | *"What does X stand for / measure?"* |
| **2. Explain** | Restate in own words | *"Explain why X matters to a beginner in 2 sentences."* |
| **3. Apply** | Use in a new scenario | *"Given situation A with constraint B, what should you do?"* |
| **4. Discriminate** | Tell look-alikes apart / spot flaws | *"Which of these 4 statements contains a subtle error? Why?"* |
| **5. Synthesize** | Combine concepts under trade-offs | *"Design a response/solution balancing X against Y."* |

## 2. Writing High-Signal Multiple Choice Questions

- Every distractor must represent a **real misconception** (never silly filler options).
- Keep all options similar in length and grammatical structure.
- Always include an `"I don't know / Chưa chắc"` option in diagnostic mode to separate lucky guesses from real mastery.

## 3. Spaced Repetition Intervals (Leitner-Inspired)

Assign the next review date based on recall quality:

| Outcome | Next Review | Action |
| :--- | :---: | :--- |
| **Wrong / Again** | **Tomorrow (1 day)** | Re-learn via analogy; re-test in a new wording |
| **Correct but Hard / Guessed** | **3 days** | Review comparison table / pitfall note |
| **Correct & Solid (Good)** | **7 days → 14 days** | Keep in interleaved cumulative mix |
| **Instant & Effortless (Easy)** | **30 days** | Graduate to monthly maintenance |
